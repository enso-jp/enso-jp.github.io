# Vietnam Guide

This repository publishes the public site at [vietnam-travelguide.com](https://vietnam-travelguide.com).

The site is built from [enso-jp/vietnam-guide](https://github.com/enso-jp/vietnam-guide) and deployed by [`.github/workflows/publish.yml`](.github/workflows/publish.yml). A push to `main` starts that workflow (`on: push: branches: [main]`). Scheduled and manual runs also publish the current `vietnam-guide` `main` branch.
